# Discovery calls and customer development (call artifacts)

## Description
How to run discovery calls that qualify deals and produce reusable product/market insights. Includes a question bank, talk/listen benchmarks, and a documentation template.

## Main sections
### Discovery call goals
In one call you should achieve:
- clarify ICP fit
- map current state (A) and desired state (C)
- identify urgency (why now)
- identify decision process + stakeholders
- agree on a single next step (demo, pilot, offer)

### Talk/listen benchmarks (directional)
Sales calls that work tend to:
- let the buyer speak more than the seller
- use many open questions

Practical targets:
- Seller talk time: **~40–45%**
- Buyer talk time: **~55–60%**
- Questions per call: aim for **~11–14** meaningful questions (open-ended)
- Duration: **~30–45 minutes** for typical B2B discovery

### Question bank (copy-paste friendly)
**Role + context**
- “What’s your role and what are your KPIs?”
- “What team/process does this touch?”

**Current state (A)**
- “How do you do this today?”
- “How much time/money does it take per week/month?”
- “Where does it break?”

**Trigger + urgency (Why now)**
- “Why are you looking at this now?”
- “What happens if nothing changes in 3 months?”

**Desired state (C)**
- “What would ‘success’ look like?”
- “Which KPI should move, and by how much?”

**Alternatives (Why you)**
- “What other options are you considering?”
- “What have you tried before? Why didn’t it work?”

**Decision + budget**
- “Who needs to approve this?”
- “How does procurement/payment work in your company?”
- Indirect budget probe: “How many people touch this today, and for how many hours?”

### Call documentation: a minimal database
If you don’t write it down, it doesn’t exist.

Store every conversation in a simple table (Sheets/Notion/CRM).

Recommended fields:
- Date
- Name, contacts
- Company, role
- Source (where they came from)
- Awareness level (optional)
- ICP fit score (0–10) and why
- Current process (A), costs
- Desired outcomes (C)
- Trigger / urgency
- Stakeholders / decision-maker
- Budget signals (direct or inferred)
- Competitors / alternatives
- Status: Active / Won / Lost / On hold
- Next step + owner + deadline
- Loss reason (when lost)

## Practical examples
### Example 1 — turning a “lost” call into value
Even if the deal is lost, extract:
- the real reason (price, urgency, trust, missing feature, wrong ICP)
- language they used to describe pain (use in marketing copy)
- competitor names (for future teardowns)

## Notes
- Don’t interrogate. Use the question bank as a map; follow the buyer’s answers with good follow-ups.
