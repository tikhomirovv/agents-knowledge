# Telegram subscriber acquisition (Telegram Ads + cross-channel)

## Description
How to buy subscribers for a Telegram channel with controllable economics: what to test, which metrics to watch (CTR, click→sub), and how to use “best posts” as landing targets.

## Main sections
### Acquisition principle: promote a post, not just a channel
If you have strong “entry posts” (high share/save, high conversion), link ads to a specific post to improve click→subscribe conversion.

### Core metrics
- **CTR**: ad clicks / impressions
- **CR click→subscribe**: subscribes / clicks
- **CPS**: spend / new subscribers

Healthy acquisition is:
- stable CTR,
- stable click→sub,
- CPS inside your modeled payback window.

### Testing loop (default)
1. Select 3 candidate entry posts.
2. Write 5 ad texts (short, benefit-first).
3. Run small daily budgets.
4. Keep winners, rotate losers weekly.

### Cross-channel bridge: Instagram/Meta → landing → Telegram
When you want more scale:
- run short video ads
- send to a simple bridge landing page with 1 CTA: “Join Telegram”
Benefits:
- easier tracking (pixels)
- message priming before Telegram click
