# Long video packaging: thumbnails, titles, retention

## Description
A practical guide to “packaging” long-form video (YouTube) for higher CTR and retention: what to test, how to lay out thumbnails, and how to stay within platform policy constraints.

## Main sections
### The two levers that move recommendations
- **CTR**: how often viewers click after seeing the impression.
- **Retention / watch time**: how long they stay; completion % is a strong proxy.

### Three universal interest buckets (use responsibly)
Many high-performing hooks map to:
- money/status/security
- health/appearance
- relationships/belonging

Guideline:
- Use the bucket only when it truly connects to the product value; avoid mismatch bait.

### Thumbnail layout heuristics (F / Z scanning)
Practical placement:
1. **Top-left**: main trigger/benefit (“How…”, “Why…”, “5 ways…”).
2. **Top-right**: contrast or secondary proof.
3. **Center**: the main visual (face/emotion, product, result).
4. **Bottom**: minimal extra context (avoid clutter).

Constraints:
- Keep text **≤ 4–5 words** (mobile readability).
- Use high contrast; test color pairings.

### Policy safety for sensitive categories
Some “high-attention” topics can be restricted in ads or content moderation (e.g., body images, unrealistic promises).

Safer reframes:
- Replace “Lose 10kg in 3 days” → “Feel better in 3 weeks”.
- Use realistic results and educational framing.

### Testing loop (what to do weekly)
1. Create 5 thumbnail variants for the same video.
2. Create 3 title variants.
3. Run A/B tests (where available) or rotate on small batches.
4. Keep variants that improve CTR without harming retention.
